# local‑supply‑agent‑demo
杭电人工智能｜个人工程实战：本地Agent + 量化模型 + ComfyUI生成管线，面向获客物料自动化

> 仓库持续更新，记录本地部署、排坑、管线搭建全过程

## ① 项目简述 & 实操卡点（对应投递要求①）
目标：验证简易端到端链路：公开线索拉取 → LLM提炼意向关键词 → 本地生成营销素材 → 打标归档
技术栈：Python / 4‑bit量化大模型 / ComfyUI节点管线 / 基础爬虫

✅ 已遇到&解决（真实排坑记录，持续更新）
1. Windows安装bitsandbytes原生失败 → 检索GitHub Issue，使用社区预编译whl，实现7B模型4‑bit量化，显存占用下降约40%
2. ComfyUI加载FLUX出现CUDA OOM显存溢出 → 开启模型权重卸载、限制分辨率832×832，稳定推理
3. 爬虫请求触发限流 → 加入请求头伪装 + 固定间隔sleep + 异常捕获，提升链路鲁棒性

## ② 想落地的业务场景（对应投递要求②）
我希望用AI重构「获客线索到营销物料」全流程：
当前很多业务依赖人工：手动筛线索 → 人工写关键词 → 找图剪辑素材，重复耗时。
完整设想链路：
爬虫拉取公开行业线索 → 本地量化7B模型提炼意向关键词 → ComfyUI自动生成适配配图 → FFmpeg批量切片成短视频片段 → 自动打标入库。
优势：尽量依靠本地推理减少云端API开销，把单条物料制作从几十分钟压缩到数分钟，直接服务获客转化。
